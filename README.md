# 📚 自考英语核心词汇 互动记忆闪卡 Web App

专为自考英语备考打造的 **极简高效互动闪卡 Web 应用** (zk-english-flashcards)。包含全量 **1311 个自考核心重点词汇**（重难点精选词 + 核心大纲词），支持 **艾宾浩斯遗忘曲线复习**、**真实 Anki 共享牌组地道例句**、**每日定量学习**、**全语音朗读** 以及 **PWA 手机桌面全屏沉浸体验**。

> **当前构建版本**: `v1.5.7`  
> **线上发布地址**: [https://santalin87.github.io/zk-english-flashcards/](https://santalin87.github.io/zk-english-flashcards/)  
> **源码仓库**: [https://github.com/santalin87/zk-english-flashcards](https://github.com/santalin87/zk-english-flashcards)

## 🌟 核心特性与重大功能说明

### 1. 🎴 闪卡直达与秒开打卡 (`v1.5.2` / `v1.5.3`)
- **秒开直达**：打开应用无需多余操作，直接直达当前活跃闪卡，让背词打卡快速切入专注状态。
- **今日任务每日锁定**：每天第一次打开时自动抽词并锁存到 `localStorage`，全天内无论如何刷新或切换标签，当天的词单和顺序 100% 保持稳定。
- **🔀 随机打卡**：支持手动点击清单右上角的“🔀 随机打卡”按钮，按需随时重新随机抽换新词单。

### 2. 📖 真实 Anki 共享牌组 (Spoonfed Anki) 极简地道例句融合 (`v1.5.4` ~ `v1.5.6`)
- **彻底剔除机械硬套模板**：彻底废除任何 `This is a useful...` 等生硬无用的机器模板句。
- **7,335 条 Spoonfed Anki 原装句库解包融合**：全量解包 Anki 官方共享社区名作 `Spoonfed_Chinese.apkg`，精准匹配替换了 **871 个自考核心词** 的例句与中文翻译！
- **$i+1$ 极简助记**：例句长度严格控制在 4 ~ 8 个单词，周边词汇 100% 为基础常用词，无任何 `...` 悬空碎片句，朗朗上口好记。

### 3. 🧩 词根词缀三大分类系统 (Roots / Prefixes / Suffixes) (`v1.5.0` / `v1.5.2`)
- **真实词根演变拆解**：彻底废除 `re- + frigerator` 式机械剥离，替换为真正的拉丁/希腊词根语义（如 `frig` = 冷/冻，`re- (反复) + frig (冷/冻) + -ate + -or (器具) ➔ 冰箱`）。
- **三大分类大框呈现**：将 44 个自考常考词根词缀分类为 **🌳 核心词根 (Roots)**、**🔤 高频前缀 (Prefixes)**、**🔠 常用后缀 (Suffixes)** 3 大容器框，芯片化极简呈现，点击小芯片直接切入该词根的专属卡片！

### 4. 📅 真实学习行为打卡与连续天数统计 (`v1.5.1`)
- **真实学习行为触发**：告别盲目打开网页即 +1 的伪打卡。只有当天产生了真实的刷卡行为（标记“记住啦”或“没记住”），系统才会记录今天的打卡并递增天数；缺席超过 1 天自动重置。

### 5. 🧠 艾宾浩斯遗忘曲线与全语音发音
- **黄金遗忘节点**：遵循 1天/2天/4天/8天/15天 遗忘曲线，每天优先推送需要复习的旧词。
- **美音双引擎发音**：支持单词朗读、高频短语发音、地道例句发音，兼容各类手机端浏览器（微信/华为/小米）。

## 🚀 本地运行与打包说明

1. **打包脚本**: 运行 `python build_full_flashcard_app.py` 即可自动读取 `target_words_data.json` 并编译打包生成最新版本的 `index.html`。
2. **线上部署**: 项目支持 GitHub Pages 自动部署，只需推送 `main` 分支即可自动同步更新线上手机端。
