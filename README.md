# 自考英语核心词汇 互动记忆闪卡 Web App

专为自考英语备考打造的 **极简高效互动闪卡 Web 应用**。包含全量 **1311 个自考核心重点词汇**（重难点精选词 + 核心大纲词），支持 **艾宾浩斯遗忘曲线复习**、**每日定量学习**、**全语音朗读** 以及 **PWA 手机桌面全屏沉浸体验**。

## 🌟 核心特性

- 📚 **1311 核心词全覆盖**：重难点精析 + 音标 + 极简高频短语 + 自然拼读 + 词根词缀拆解演变 + 自考例句。
- 🧠 **艾宾浩斯记忆法**：遵循黄金遗忘节点（1天/3天/7天/15天），每日点开自动优先推送复习词。
- 📅 **每日定量自定**：支持自由选择每日学习目标（20 / 30 / 50 / 100 词/天）。
- 🔊 **全语音发音覆盖**：支持单词发音、高频短语发音、自考例句朗读，并支持自主切换美音/男声/女声发音人。
- 🎯 **精准区域防误触**：点击音标/单词读音，点击例句框读例句，点击空白区顺畅翻页。
- 📱 **PWA 手机桌面全屏**：添加到手机主屏幕后自动开启无地址栏沉浸全屏模式。

## 🚀 部署说明

使用 Cloudflare Pages 或 GitHub Pages 即可实现一键零成本在线部署。主入口文件为 `index.html`。
